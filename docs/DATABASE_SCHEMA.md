# Database schema

The `students` table is defined in `database/schema.sql`. It has an auto-increment `id` primary key and a unique `email`. Dates use `DATE`, attendance/CGPA use fixed-precision `DECIMAL`, and `created_at` is generated by the application on insert.

Useful query: `SELECT department, COUNT(*) FROM students GROUP BY department;`

Useful query: `SELECT full_name, attendance_percentage FROM students WHERE attendance_percentage < 75;`
